Data Deletion

clipfarm — last updated 3 October 2026

There is no server to delete data from

clipfarm runs entirely on the operator's own computer. It has no backend, no hosted database and no user accounts. We never receive your video, captions, tokens or usage data, so there is nothing held on our side to erase.

Revoking access to your Instagram account

If you connected an Instagram account to clipfarm, you can revoke it at any time from Instagram itself:

  • Instagram app → Settings and privacy → Website permissions → Apps and websites → remove clipfarm.

Revoking immediately invalidates the access token. clipfarm can no longer read your profile or publish on your behalf.

Deleting the data held locally

Everything clipfarm stores lives in two places on the operator's machine. Deleting them removes all of it permanently:

  • .env — access and refresh tokens
  • storage/ — the local database, rendered clips, transcripts and thumbnails

Requesting deletion

Because no data leaves the operator's machine, there is no remote request to make. If you believe an operator holds content of yours and you want it removed, contact the operator of that installation directly; they control the files.

This describes software that runs entirely on the operator's own machine. It is not legal advice.
